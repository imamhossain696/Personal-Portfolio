# Personal Portfolio Website

A responsive student portfolio built with semantic HTML, custom CSS, Tailwind CSS (CDN), and a little JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. No build step is required.
3. An internet connection is needed for the Tailwind CDN and Google Fonts.

## Customize before submitting
Search `index.html` and replace the sample content:
- `Alex Morgan` and the `am.` logo with your name/brand.
- The hero introduction, location, and profile image URL.
- About section, skills, project titles/descriptions, and project links.
- Education institution, degree/course, and study dates.
- `hello@example.com`, GitHub, and LinkedIn URLs.
- Update the page title and meta description.

The three project cards are illustrative previews. Replace them with screenshots of your own projects and real demo/source links.

## Contact form
The form currently demonstrates front-end interaction only. It does not send email or store submissions. Connect it to Formspree, Netlify Forms, or your own backend to receive messages.

## Technologies
- HTML5
- CSS3
- Tailwind CSS via CDN
- Vanilla JavaScript

## Responsive behavior
The layout uses responsive Tailwind utility classes and CSS breakpoints. The mobile navigation collapses into a menu, project and skill grids adapt to screen width, images scale fluidly, and horizontal overflow is hidden.
